# gitHub_Practice

## HW #4.3: Diamonds, Women's Basketball, and Monte Carlo Integration

### About This Project
This repository holds my work for HW #4.3. The files are labeled and displayed as 3.4 as I had mistaken the numers for the homework. The reproducible Quarto report covers four tasks:
1. Descriptive statistics for the length, width, and depth of round cut
   diamonds, grouped by color
2. A bar chart of free throws attempted per season in NCAA women's basketball
3. A Monte Carlo estimate of a chi-square (df = 5) integral from 0 to 20
4. A plan, create, improve, and polish process for a graph of diamond price
   per carat by cut

### Data Sources
- Diamonds: the diamonds data set from the {ggplot2} R package.
- Women's basketball: team_box.csv from the Big 10 Academic Alliance
  Love Data Week competition
- Monte Carlo: no external data as points are simulated in the report

Branches: main branch holds finished work while dev_tat is where changes are made and
then merged into main through pull requests.
